# Guião — vídeo curto do fundador (proposta)

**Estado:** guião por gravar. Não existe vídeo aprovado; o site não tem nenhum espaço reservado para vídeo. Só integrar quando houver um ficheiro real, aprovado por Thiago, com legendas.

- **Duração:** 60 a 75 segundos.
- **Formato:** Thiago a falar para a câmara, plano médio, fundo simples. Vertical (9:16) para redes sociais e horizontal (16:9) para o site, se for usado.
- **Legendas:** sempre (muitas pessoas veem sem som). Português europeu; versão inglesa só se houver uso.
- **Tom:** calmo, próximo, sem música dramática, sem números nem promessas.
- **Não dizer:** "garantimos", "vai ganhar", "tem direito a", "a empresa está errada", "resolvemos tudo", estatísticas, nomes de empresas.
